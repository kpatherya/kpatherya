### Projects

**[Flash-Fusion](https://github.com/kpatherya/flash-fusion)**
Natural-language queries over IoT sensor streams, compiled into typed plans and executed deterministically.
📉 **95% lower latency · 98% lower token cost** vs. feeding raw telemetry to an LLM.
[![arXiv](https://img.shields.io/badge/arXiv-2511.11885-b31b1b.svg)](https://arxiv.org/abs/2511.11885) [![Demo](https://img.shields.io/badge/demo-live-2ea44f.svg)](https://flash-fusion.vercel.app/)

**[POLARIS](https://github.com/kpatherya/polaris)**
Vision-language pipeline matching landmarks across seasonal change — OWL-ViT → FastVLM → depth → RANSAC.

**[Sting-Sense](https://github.com/kpatherya/sting-sense)**
Bus-fleet telemetry system: Zephyr firmware on nRF9160 ([bus-rtos](https://github.com/kpatherya/bus-rtos)) with route congestion analytics.
[![Demo](https://img.shields.io/badge/demo-live-2ea44f.svg)](https://sting-sense.vercel.app/)

**[SIT-UP](https://github.com/kpatherya/situp)**
Camera-based posture sensing with intervention prototypes.
